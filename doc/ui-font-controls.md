# Panda Live 字体与控件外观改进方案

| 项目 | 内容 |
|---|---|
| 版本 | 0.2（评审稿 · 基于真实 UI 重做） |
| 日期 | 2026-11-25 |
| 范围 | **仅字体 + 控件外观**，不改布局、不改功能 |
| 基线 | 真实构建产物 `dist/` + 真实 `src/styles/base.css`，非任何手绘原型 |
| 关联 | 深色主色改蓝见独立方案 `doc/ui-dark-blue.md`，两者可分别采纳、已一并落地 |

> **本方案回答一个问题**：在完全不动布局的前提下，只调整字体和控件外观，能让当前真实的 panda-live 界面提升多少？
>
> 与 0.1 稿的区别：0.1 稿的效果图是基于另一个未采纳的布局改版原型（Atlas）做的，底稿不是你的真实界面，已作废。本稿**所有数据与配图均来自真实 panda-live 构建产物**。

## 2. 现状问题（实测）

### 2.1 字号碎片化：12 档，含 0.5px 碎档

对 `src/styles/base.css` 全文件 `font-size` 统计：

| 字号 | 次数 | 字号 | 次数 |
|---|---|---|---|
| 12px | 46 | 10px | 7 |
| 11px | 37 | 13px | 5 |
| 11.5px | 22 | 15px | 2 |
| 10.5px | 18 | 14px | 2 |
| 12.5px | 14 | 9.5px | 1 |
| 8px | 1 | 24px | 1 |

**问题**：8 / 9.5 / 10 / 10.5 四档过小且差异无意义；11 / 11.5 / 12 / 12.5 四档挤在 1.5px 区间内，肉眼几乎等同，读者只能靠颜色而非字号判断层级。

关键控件的浏览器实测值（真实界面）：

| 控件 | 字号/字重 | 圆角 | 高度 |
|---|---|---|---|
| `.toolbar` | 13px / 400 | 0 | 40px |
| `.brand-name` | 13px / 600 | 0 | 16px |
| `.toolbar-doc-name` | 12.5px / 600 | 0 | 16px |
| `.icon-button` | 11.5px / 400 | 3px | 28px |
| `.sidebar-tab` | 11.5px / 400 | 0 | 33px |
| `.sidebar-tab-badge` | 10px / 400 | 8px | 16px |
| `.tab` | 12.5px / 400 | 0 | 33px |
| `.tab-item.active` | 13px / 400 | 0 | 33px |
| `.tab-close` | — | **2px** | 22px |
| `.mode-button` | 13px / 400 | **2px** | 24px |
| `.tree-row` | 12.5px / 400 | 0 | 22px |
| `.statusbar` | 11.5px / 400 | 0 | 24px |
| `.statusbar-button` | 11.5px / 400 | **2px** | 22px |

### 2.2 字重不参与层级

实测几乎所有控件都是 `font-weight: 400`，活动标签 `.tab-item.active` 的字重仍是 400——活动态只靠背景和底部色条区分。文档名（600）与正文说明权重相同，层级靠颜色硬撑。

### 2.3 圆角不统一

base.css 中 `border-radius: 2px` 出现 **47 处**，与 3px / 6px / 8px 混用。同类控件里：图标按钮 3px、模式按钮 2px、标签关闭 2px、状态栏按钮 2px、徽标 8px——五种控件三种圆角。

### 2.4 焦点环过弱

全局 `:focus-visible`（第 183 行）为 1px 实线 + 1px 偏移，在高密度界面下键盘定位困难。

## 3. 设计原则

1. **零布局位移**：只替换外观属性值，`height / padding / margin / gap / flex / width` 全部冻结。结构区域 before/after 逐元素测量必须完全一致。
2. **收敛而非重设计**：把 12 档字号收敛到 6 档，把碎档并入相邻档，不为改而改。
3. **字重建立层级**：用 400/500/600 区分正文 / 控件 / 强调，不靠堆颜色。
4. **同控件同外观**：同类控件统一圆角、边框、焦点态。
5. **可独立回滚**：所有改动集中在一个覆盖层，评审通过后再合入，出问题可整层撤销。

## 4. 字体方案

### 4.1 字号收敛表

| 新 token | 新值 | 取代现状字号 | 用途 |
|---|---|---|---|
| `--fs-2xs` | **11px** | 8 / 9.5 / 10 / 10.5 | 角标、快捷键、极小提示 |
| `--fs-xs` | **12px** | 11 / 11.5 | 图标按钮、状态栏、侧栏标签 |
| `--fs-sm` | **13px** | 12 / 12.5 | 标签、树节点、工具栏文档名 |
| `--fs-base` | **14px** | 13 / 14 | 正文、文档名 |
| `--fs-lg` | **15px** | 15 | 面板主标题（保持） |
| `--fs-2xl` | **24px** | 24 | 空状态主标题（保持） |

> 8px 并入 11px 是本次提升幅度最大的一档，但 8px 仅出现 1 次（极小提示），不影响布局。

### 4.2 字重层级

| 层级 | 字重 | 应用 |
|---|---|---|
| 正文 / 辅助 | 400 | 树节点、状态栏元信息、说明文字 |
| 控件 | 500 | 图标按钮、模式按钮、侧栏标签、标签名 |
| 强调 | 600 | 活动标签、文档名、品牌名、徽标 |
| 大标题 | 600 | 仅 24px 空状态标题（不用 700，避免中文伪粗糊边） |

### 4.3 字距与行高

- 控件行高沿用现状，不改（保证零位移）。
- 正文/面板说明必要时统一 `line-height: 1.6`。
- 13px 及以上标题加 `letter-spacing: -0.01em`；11/12px 不加，保证小字可读。
- 等宽信息（行号、路径、时间）保持 `--font-mono`，不套 UI 字距。

## 5. 控件外观方案

### 5.1 圆角统一

| 控件 | 现状 | 改进 |
|---|---|---|
| `.icon-button` | 3px | 5px |
| `.mode-button` | 2px | 5px |
| `.tab-close` | 2px | 5px |
| `.statusbar-button` | 2px | 5px |
| `.files-folder-select` | 3px | 5px |
| `.sidebar-tab-badge` | 8px | 999px（胶囊） |

新增 `--radius-ctl: 5px`；同类控件统一引用。圆角变化不影响盒模型尺寸。

### 5.2 焦点环

`:focus-visible` 由 `1px solid accent / offset 1px` 改为 `2px solid var(--focus-ring) / offset 2px`。新增 `--focus-ring`，深浅两套：

| 主题 | 值 | 来源 |
|---|---|---|
| 浅色 | `rgba(11,107,79,.5)` | 取浅色 `--accent` 的 RGB |
| 深色 | ~~`rgba(65,191,149,.55)`~~ → `rgba(88,166,255,.55)` | 原取深色亮绿 `#41bf95`，已废弃；改蓝方案见 `doc/ui-dark-blue.md` |

> **关于深色主色**：本字体控件方案本身**不改动主色**。深色焦点环原为绿色 `rgba(65,191,149,.55)`，但因深色改蓝方案（`doc/ui-dark-blue.md`）已取代它，深色值以蓝色 `rgba(88,166,255,.55)` 为准；浅色焦点环不受影响。对应的深色绿色效果图（`ui-font-controls-dark-*.png`）已随方案替换移除。

### 5.3 按钮层次

主按钮 `.button.primary` 增加极淡投影 `--shadow-ctl: 0 1px 2px rgba(16,24,40,.06)`，与次级按钮拉开层次；避免用"分隔线色"当按下背景。

### 5.4 图标

Lucide 24×24 viewBox 与显示尺寸全部不变，仅 `stroke-width: 2 → 1.8`，线性更精致。

## 6. 布局位移实测（真实 UI 验证）

在同一真实页面上切换覆盖层前后，用 `getBoundingClientRect()` 逐元素测量（视口 1440×900）：

**7 个结构区域 x / y / 宽 / 高差异全部为 0：**

| 区域 | x | y | 宽 | 高 |
|---|---|---|---|---|
| `.toolbar` | 0 | 0 | 0 | 0 |
| `.sidebar` | 0 | 0 | 0 | 0 |
| `.sidebar-tabs` | 0 | 0 | 0 | 0 |
| `.tabstrip` | 0 | 0 | 0 | 0 |
| `.mode-bar` | 0 | 0 | 0 | 0 |
| `.workspace` | 0 | 0 | 0 | 0 |
| `.statusbar` | 0 | 0 | 0 | 0 |

**控件外观变化（盒高度全部不变）：**

| 控件 | 字号 | 字重 | 圆角 | 盒尺寸 |
|---|---|---|---|---|
| `.toolbar-doc-name` | 12.5→14px | 600→600 | — | 66×16 → 74×18 ⚠️ |
| `.icon-button` | 11.5→12px | 400→500 | 3→5px | 30×28 不变 |
| `.sidebar-tab` | 11.5→12px | 400→600 | — | 尺寸不变 |
| `.sidebar-tab-badge` | 10→11px | 400→600 | 8→999px | 16×16 不变 |
| `.tab` | 12.5→13px | 400→600 | — | 宽 +6px（文字度量） |
| `.tab-close` | — | — | 2→5px | 22×22 不变 |
| `.mode-button` | 13px | 400→500 | 2→5px | 30×24 不变 |
| `.statusbar-button` | 11.5→12px | 400→400 | 2→5px | 宽 +3px |
| `.tree-row` | 12.5→13px | 400→400 | — | 259×22 不变 |

> ⚠️ 唯一例外：`.toolbar-doc-name` 因字号 12.5→14px、行高为 `normal`，高度从 16→18px（+2px）。工具栏高 40px，仍有充足余量，不会溢出；如需绝对零位移，可把文档名保持 `--fs-sm`（13px）不升到 14px。其余控件宽度 +1~8px 属字号变化引起的自然文字度量差异，非布局属性改动。

## 7. 实施清单

评审通过后，把 `doc/ui-font-controls.css` 的值合入 `src/styles/base.css`：

1. `:root` 与 `:root[data-theme="dark"]` 新增字号 / 圆角 / 焦点环 / 阴影 token。
2. §5.1 列出的选择器替换 `border-radius` 为 `var(--radius-ctl)`。
3. 主界面控件的硬编码字号按 §4.1 映射表替换为 token（详见下方"落地范围"）。
4. 控件补 `font-weight: 500`，活动态补 600。
5. 全局 `:focus-visible` 换成 2px + offset 2px。
6. `.button.primary` 补投影；图标 `stroke-width: 1.8`。
7. 跑 `npm run verify`（lint + test + build），并用 before/after 截图复核零位移。

**落地范围（已实施）**：本轮只替换评审稿覆盖层明确列出的主界面控件字号——工具栏、文档名、图标按钮、侧栏 tab、徽标、标签、状态栏、目录树。其中 `.tree-row` 与 `.tree-name` 需同时替换（后者自带字号会覆盖父级）。文档中残留的碎字号（137 处）与 `border-radius: 2px`（42 处）属于弹层、菜单、设置页、预览器等内部组件，**不在评审稿范围内**，本轮刻意不改——强行全文替换会改变这些区域的信息密度，且无效果图验证，与"零位移"验收目标冲突。

**注意**：`.toolbar-doc-name` 行高为 `normal`，升到 14px 后高度 16→18px（+2px），工具栏 40px 有余量不溢出；其余控件盒高度不变。

## 9. 范围边界

本方案**只改字体与控件外观，不改任何布局属性**（height / padding / margin / gap / flex / width 一律不动），在当前真实布局上独立落地、独立回滚。

深色主题的主色改蓝是另一份独立方案 `doc/ui-dark-blue.md`，两者可分别采纳；本轮已一并落地到 `src/styles/base.css`。
