# Panda Live 控件图标语义优化

| 项目 | 内容 |
|---|---|
| 版本 | 1.0（已落地） |
| 日期 | 2026-11-25 |
| 范围 | 控件图标语义、图标风格一致性；不改布局、不改功能、不改配色 |
| 基线 | 已完成字体/配色、UI 样式专业化两轮优化的真实构建产物 |
| 效果图 | `doc/ui-icons-compare.png`（真实界面前后 + 图标对照表）、`doc/ui-icons-after.png`、`doc/ui-icons-git.png` |

> 目标：让每个图标表达它所在控件真正执行的动作，消除“一个图标两个功能”和“两个图标一个功能”，并把描边风格收敛到单一来源。

---

## 1. 盘点结论

项目使用自建 Lucide 风格 SVG 图标（`src/app/icons.tsx`，约 60 个）与少量内联 SVG 字符串（`toolbar-icons.ts` 等）。全量盘点后发现四类问题：

| 类别 | 典型问题 | 影响 |
|---|---|---|
| 一图标两功能 | `file-plus` 同时表示「新建文件」与「Git 暂存」；`list` 同时表示「大纲」与「全部标签」 | 用户按字面误读操作含义 |
| 一功能两图标 | 「打开文件」在工具栏用 `file`、空态用 `folder-open` | 同一命令视觉不一致 |
| 语义不符 | 取消暂存用回转箭头、性能用心电线、1:1 用旗形 | 需要读 tooltip 才能理解 |
| 风格漂移 | 描边存在 1.75 / 1.8 / 2.0 / 2.4 四档，且 CSS 覆盖组件属性 | 同界面图标粗细不一 |

---

## 2. 图标替换清单

| # | 控件 | 原图标 | 新图标 | 依据 |
|---|---|---|---|---|
| 1 | Git 面板「暂存 / 标记为已解决」 | `file-plus` | `plus` | `file-plus` 字面是“新建文件”，与新建文档撞车；`+` 是版本控制暂存惯例 |
| 2 | Git 面板「取消暂存」 | `reset` | `minus` | 回转箭头读作“重置”，与 `refresh` 形状相似；`−` 与 `+` 成对表达移出暂存 |
| 3 | 空态「打开文件」 | `folder-open` | `file` | 实际调用 `openFiles()`，与工具栏同命令统一，也不再与「打开文件夹」混淆 |
| 4 | 侧栏「大纲」标签 | `list` | `list-tree` | 汉堡列表与「全部标签」撞车；缩进树 + 节点圆点更贴合大纲/目录结构 |
| 5 | 状态栏「显示改动」 | `compare` | `diff` | `compare` 专留给 GitPane 的「对比视图」；`diff` 用左减右加表达增删差异 |
| 6 | 性能浮层 | `activity` | `gauge` | 心电线像健康监测，仪表盘更贴近性能指标 |
| 7 | 图表缩放「1:1」 | `default-view` | 带 `1:1` 字标的方框 | 原旗形读不出比例，字标一眼可辨，与「页宽显示」不再混淆 |

新增 5 个图标：`plus`、`minus`、`list-tree`、`gauge`、`diff`；重绘 `default-view`。

## 3. 风格与尺寸收敛

| 项目 | 调整 | 说明 |
|---|---|---|
| 描边单源 | `Icon` / `OutlineSymbolIcon` 默认 `strokeWidth` 统一为 **1.8**；删除 `base.css` 中对 `.icon-button svg` 等的 `stroke-width: 1.8` 覆盖 | 原先组件 1.75、CSS 局部覆盖 1.8，改为组件自身单一来源 |
| 内联 SVG | 渲染区复制/放大助手图标 `2` → `1.8`；块工具栏图标保持 `1.8` | 与 React 图标体系一致；CodeMirror 折叠箭头保持 `2.4`（编辑器内部折行需要更高辨识度） |
| 配对尺寸 | 侧栏折叠/展开 `14 / 15` → 统一 `14`；折叠 rail 标签 `15` → `14` | 成对控件尺寸一致，折叠态不大于展开态 |
| 模态关闭 | 设置 / 问题面板 / 图表查看器 `16` → `14` | 与标签、Toast 的关闭按钮收敛到同一档 |
